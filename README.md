# Sanket Muchhala - 3D Interactive Portfolio

A stunning 3D bedroom scene that serves as an interactive portfolio website, showcasing AI/ML engineering expertise through clickable objects and immersive storytelling.

## 🌟 Features

- **Immersive 3D Environment**: Fully interactive bedroom scene built with Three.js
- **Interactive Objects**: Click on laptops, monitors, books, and other items to explore portfolio content
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Performance Adaptive**: Automatically adjusts quality based on device capabilities
- **Smooth Animations**: Professional entrance animations and lighting effects
- **Portfolio Integration**: Complete integration with Sanket's professional information

## 🛠️ Tech Stack

- **Frontend**: Pure HTML, CSS, JavaScript (no external dependencies except Three.js)
- **3D Graphics**: Three.js (r128)
- **Architecture**: Modular ES6 classes with clean separation of concerns
- **Performance**: Adaptive quality settings and performance monitoring
- **Deployment**: GitHub Pages compatible

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/sanketmuchhala/3D-portfolio.git
   cd 3D-portfolio
   ```

2. **Serve the files** (required for Three.js to work)
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

3. **Open in browser**
   ```
   http://localhost:8000
   ```
